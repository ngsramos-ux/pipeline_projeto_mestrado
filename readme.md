# Malha Fina Contábil - TCU (Inteligência Artificial)
Repositório contendo o pipeline de dados, modelagem de Machine Learning (Isolation Forest) e Dashboard Interativo em Streamlit desenvolvidos para dissertação de mestrado.

### Estrutura do Projeto
- `01_etl_limpeza.py`: Extração e transformação de dados do Tesouro Gerencial.
- `02_modelagem.py`: Algoritmo Isolation Forest e explicabilidade com SHAP.
- `03_dashboard_tcu.py`: Interface web interativa.
